The node editor does what it says, helps you edit nodes for SCUM.

Buttons:
Load JSON
  Select a json node file to open.
Expand All
  Expands all child items.
Collapse All
  Collapses all child items.
Undo
  Undo last step, multiple undos are possible, not sure what the limit is, pretty sure it’s all since every change is tracked.
Clear
  Clears the currently loaded node file.
Visual
  Open the visual editor.
Save As
  Create a new file
Save
  Override current file.

How to make Changes
Right Click an item and you will see the context menu.
Edit Name
  Change the name of the current item
Edit PostSpawnActions
  Allows you to add post spawn actions.
Change Rarity
  Change rarity of the item, such as abundant, common, uncommon etc.
Add Child
  Adds a child to the current selected node.
Remove Node
  Removes the selected node, if it has children they will be removed too.

Visual Editor
  All of these changes can also be done in the visual editors by right clicking.
  Click a slice in the visual editor to drill down a level.
  If a slice is darkened and no items appear on hover, then there are no children.
  Use the breadcrumbs at the top of the screen to move back up a level or more.
